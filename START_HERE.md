## 🔄 Workflow Overview

```
User Action
    ↓
Local Save (Instant)
    ↓
Try to Sync
    ├→ Internet Available?
    │  └→ YES: Send to server
    │  └→ NO: Queue for later
    ↓
User Notified
    ├→ ✓ Synced
    ├→ ⧖ Pending Sync
    └→ ⊙ Offline Mode
```
